# DUELIST

Pixel-Duelle in der Arena über den Wolken – gegen den Bot (4 Schwierigkeitsstufen) oder zu zweit an einem Gerät.
Läuft im Browser auf PC und Handy, komplett offline.

**Spielen:** über GitHub Pages (Link oben rechts im Repo unter „Deployments“ bzw. `https://<benutzername>.github.io/<repo>/`).
Auf dem Handy: Seite öffnen → „Zum Startbildschirm hinzufügen“ → spielt sich wie eine App, auch ohne Internet.

## Lokal starten
- Windows: `DUELIST starten.bat` doppelklicken
- oder: `npm install` und `npm start` → http://localhost:8080

## Steuerung
| | Gegen Bot | Spieler 1 | Spieler 2 |
|---|---|---|---|
| Bewegen | WASD / Pfeile | WASD | IJKL / Pfeile |
| Angriff | J / E | E | O |
| Fähigkeit | K / R | R | P |
| Ausweichen | L / Leertaste / Shift | Q | U |

Gamepad und Touch (Joystick + Knöpfe) werden ebenfalls unterstützt.
